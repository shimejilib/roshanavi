# roshanavi 利用ガイド

roshanavi を使ってノードを開発する人のための、使い方の説明です。ROS 2 や Python のパッケージの仕組みに詳しくなくても読めるように書いています。設計の詳しい説明は [docs/design/](../design/) にあります。

| 章 | 内容 |
|---|---|
| [既存の launch ファイルごと roshanavi で動かす](takeover.md) | `--launch` で今の launch ファイルのノードを roshanavi に起動させる、2 つの動かし方 (ノードごと / 全体)、launch ファイルを書き換えたとき、強制終了で残ったノードの片付け、いらないノードの削除 |
| [自分のコードを関数・クラスノードにする](user-code.md) | 自分の Python のコードをどこに置けば使えるか (A / B / C)、「ひな形を作る」、依存ライブラリの入れ方 (① rosdep ② 仮想環境)、よくあるつまずき、git のサブモジュール |

章は順に増やしていきます (画面の見方、入力ノード、ランチャー、シナリオ …)。
